# User Stories

Reference the Writing User Stories final project guide in the course portal for more information about how to complete each of the sections below.

## Outline User Roles

1. **Casual Player**: Engages with games for relaxation; prioritizes quick session logging and personalized game recommendations.
2. **Completionist**: Highly engaged player focused on granular data, tracking playtime streaks, and hitting 100% completion metrics.

## Draft User Stories

1. As a Casual Player, I want to keep a personal list of games I own, so that I have a central record of my gaming library.
2. As a Casual Player, I want the app to suggest a game based on my current mood and energy level, so that I can quickly pick a game without decision fatigue.
3. As a Casual Player, I want to add a personal rating and short review to a game, so that I can easily browse my past thoughts alongside my library.
4. As a Casual Player, I want to record when I play a game and how long the session lasted, so that I can monitor my basic time investment.
5. As a Casual Player, I want to move games between my backlog, playing, and completed statuses, so that I can organize my current focus.
6. As a Completionist, I want to log milestones and achievement statuses for any game, so that I can track my exact progression.
7. As a Completionist, I want to set playtime goals and track consecutive days played, so that I maintain my streak and finish my backlog.
8. As a Completionist, I want to set a priority level for games in my wishlist, so that I can systematically decide what to play next.
9. As a Completionist, I want to see a Stats Dashboard with completion counts and total hours played, so that I can visualize my long-term gaming habits.
10. As a Completionist, I want to view, create, edit, and delete my play sessions, so that my logged data remains perfectly accurate over time.
